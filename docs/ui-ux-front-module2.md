## UI/UX задачи для фронта (`module2`)

- **Магазин и заказы**
  - Добавить страницу «Мои заказы» с:
    - списком заказов по `orderId` и статусу (данные из Java `/api/v1/orders`),
    - деталкой заказа (товары, сумма, статус оплаты/доставки).
  - После оформления заказа:
    - показать экран подтверждения с краткими данными заказа и кнопками:
      - «Вернуться на карту»,
      - «Перейти к заказам».
  - Унифицировать тексты ошибок при проблемах с оплатой/созданием заказа, использовать один компонент уведомлений.

- **Карты и маршруты**
  - Добавить избранное:
    - возможность отметить POI и маршруты как «избранные» (локально в `localStorage`),
    - фильтр «Показать избранное» на карте и в списке маршрутов.
  - Для карточек маршрутов:
    - добавить чёткий CTA «Начать маршрут» / «Открыть на карте» с единым расположением кнопок.

- **Формы (контакты, checkout, предложения POI)**
  - Ввести единый паттерн отображения ошибок:
    - красный текст под полем,
    - подсветка бордера поля,
    - текст‑подсказка рядом с обязательными полями.
  - Добавить `aria-invalid`, `aria-describedby` для полей с ошибками.
  - В форме обратной связи и checkout:
    - показывать индикатор отправки (disabled кнопка, спиннер).

- **Доступность и навигация**
  - Добавить skip‑link «Пропустить навигацию» в начало `App.vue`.
  - Обеспечить видимый фокус для всех интерактивных элементов (свойство `outline` или кастомная подсветка).
  - Проверить контрастность текста/иконок на кнопках и бейджах (особенно на `--accent` фоне).

- **Хедер и глобальный UX**
  - В `AppHeader`:
    - добавить ARIA‑ролі (`role="navigation"`, `aria-label` для основного меню),
    - сделать состояние активного маршрута более заметным (подчёркивание или нижняя полоска).
  - На мобильном:
    - убедиться, что все кнопки ≥ 44×44px, убрать мелкие «невидимые» кликабельные зоны.
