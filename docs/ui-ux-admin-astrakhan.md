## UI/UX задачи для админки (`astrakhan-admin`)

- **Обработка ошибок**
  - Добавить кастомный `error.html` в `templates/` в стиле `astra`:
    - дружелюбное сообщение (что случилось и что делать),
    - кнопка «Вернуться в панель»,
    - лог‑id/время для быстрой диагностики.
  - Подключить его через Spring Boot error handling (controller advice или стандартный `error` view).

- **Списки (POI, маршруты, товары, заказы, обращения)**
  - Для всех `list.html`:
    - добавить поиск по ключевым полям (название, категория, статус),
    - фильтры по статусам (опубликовано/черновик/архив, статус заказа),
    - сортировку по клику по заголовкам таблицы.
  - Ввести единый шаблон «toolbar над таблицей»:
    - слева — фильтры и поиск,
    - справа — кнопка «Создать» / «Добавить».

- **Формы редактирования контента**
  - Разбить длинные формы на секции:
    - «Основное» (название, описание, категория),
    - «Медиа» (картинки),
    - «Публикация» (статус, даты),
    - «Дополнительно» (SEO/теги и т.п.).
  - Внизу формы:
    - сделать sticky‑зону с кнопками «Сохранить», «Отмена»,
    - выровнять primary CTA всегда справа.
  - Для загрузки картинок:
    - показывать превью,
    - явно указывать ограничения по размеру/формату.

- **Навигация и мобильный UX**
  - Проверить sidebar:
    - подсветка активного раздела,
    - логичные группы (Контент / Маркетинг / Справочники / Настройки).
  - На мобильных:
    - убедиться, что все элементы sidebar и кнопки форм ≥ 44×44px,
    - обеспечить удобный горизонтальный скролл таблиц (уже частично реализовано в `admin.css` — довести до единообразия).

- **Доступность и единый стиль**
  - Привести кнопки, бейджи и алерты к значениям из `design-system/astra.css`:
    - использовать `btn`, `btn-primary`, `btn-ghost`, `tag`, `status-badge`.
  - Добавить ARIA‑атрибуты в таблицах и формах (заголовки, описания полей).
