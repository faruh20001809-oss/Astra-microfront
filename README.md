Микрофронтенд-проект с тремя основными модулями:

- `module2` — пользовательский frontend (карта, маршруты, заказы, ЛК)
- `astrakhan-admin` — Java/Spring backend и админ-контур
- `module3` — Python/Flask тех-админка и аналитика
