Массовая загрузка точек/маршрутов

← К списку точек

Вставьте JSON с массивом pois и опционально routes. Точки будут созданы как черновики без картинок — затем для каждой можно открыть редактирование и вложить изображения.

Формат: {"pois":[{"name":"...","category":"...","latitude":46.35,"longitude":48.04,"description":"...","address":"..."}],"routes":[{"name":"...","description":"...","category":"...","poiOrder":[0,1,2]}]}. poiOrder — индексы точек в массиве pois (0 = первая созданная точка).
