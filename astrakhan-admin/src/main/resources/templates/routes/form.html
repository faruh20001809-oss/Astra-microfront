Поддерживаемые форматы медиа-ссылок (модуль пользователя)
🎥 Видео
  • YouTube — youtube.com/watch?v=..., youtu.be/..., youtube.com/shorts/..., youtube.com/embed/...
  • Rutube — rutube.ru/video/...
  • Прямые файлы — любой URL с расширением .mp4, .webm, .ogg
  • Другие URL — любой https:// URL будет встроен как iframe (VK Video, Vimeo, Дзен и т.д.)
🎧 Аудио
  • Прямые файлы — URL с расширением .mp3, .ogg, .wav, .aac, .m4a
  • Ссылка должна быть прямой (открывается в браузере как аудио-файл)
  • Стриминговые сервисы (Яндекс.Музыка, SoundCloud) — только если есть прямая ссылка на файл

Указывайте по одной ссылке в строке. Ссылки должны начинаться с http:// или https://.
