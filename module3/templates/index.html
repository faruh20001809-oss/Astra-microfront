Интеграция с Grafana

Для подключения своего Grafana Dashboard:

Шаг 1: Установка Grafana
  • Windows: скачайте с grafana.com
  • Запустите: grafana-server.exe
  • Откройте: http://localhost:3000
Шаг 2: Настройка Data Source
  • Configuration → Data Sources
  • Добавьте источник (Prometheus, InfluxDB, PostgreSQL)
Шаг 3: Создание Dashboard
  • Create → Dashboard
  • Добавьте панели с метриками
  • Сохраните dashboard
Шаг 4: Разрешить iframe
  • Настройки → Security → Grafana instance URL
  • Или добавьте в grafana.ini:
    allow_embedding = true
Шаг 5: Добавьте iframe в код
